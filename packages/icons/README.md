# @open-figment/icons

The Open Figment icon set: 91 outline icons drawn to one spec (24px grid, 1px round strokes, 12px live area), as tree-shakable React components and plain SVG files. Icons use `currentColor`.

## Install

```bash
npm install @open-figment/icons
```

```bash
pnpm add @open-figment/icons
```

```bash
yarn add @open-figment/icons
```

## Use

```tsx
import { IconPlus, IconFrame, Icon } from '@open-figment/icons';

<IconPlus />
<IconFrame size={16} title="Frame" />
<Icon name="chevronDown" />
```

SVG files: `@open-figment/icons/svg/<name>.svg`.
