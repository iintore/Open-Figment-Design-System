# @open-figment/page-row

One page in the Pages list of the File panel.

Part of the [Open Figment design system](https://open-figment-design-system.vercel.app). Exports: `PageRow`.

## Install

```bash
npm install @open-figment/page-row
```

```bash
pnpm add @open-figment/page-row
```

```bash
yarn add @open-figment/page-row
```

## Use

```tsx
import '@open-figment/tokens/tokens.css'; // once per app
import '@open-figment/page-row/styles.css';
import { PageRow } from '@open-figment/page-row';

<PageRow name="Design" active onSelect={open} />
```

Every prop is typed and documented in the editor. Full reference, states and rules: https://open-figment-design-system.vercel.app/components/page-row
