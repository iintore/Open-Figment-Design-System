# @open-figment/badge

A small label that marks status or tier next to a name: Free next to Drafts, No AI on the local assistant.

Part of the [Open Figment design system](https://open-figment-design-system.vercel.app). Exports: `Badge`.

## Install

```bash
npm install @open-figment/badge
```

```bash
pnpm add @open-figment/badge
```

```bash
yarn add @open-figment/badge
```

## Use

```tsx
import '@open-figment/tokens/tokens.css'; // once per app
import '@open-figment/badge/styles.css';
import { Badge } from '@open-figment/badge';

<Badge>Free</Badge>
```

Every prop is typed and documented in the editor. Full reference, states and rules: https://open-figment-design-system.vercel.app/components/badge
