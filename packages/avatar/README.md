# @open-figment/avatar

A collaborator's initial on their cursor colour: in the properties header, comment threads and the home account.

Part of the [Open Figment design system](https://open-figment-design-system.vercel.app). Exports: `Avatar`, `AvatarStack`.

## Install

```bash
npm install @open-figment/avatar
```

```bash
pnpm add @open-figment/avatar
```

```bash
yarn add @open-figment/avatar
```

## Use

```tsx
import '@open-figment/tokens/tokens.css'; // once per app
import '@open-figment/avatar/styles.css';
import { Avatar } from '@open-figment/avatar';

<Avatar name="Ada" color="#14ae5c" />
```

Every prop is typed and documented in the editor. Full reference, states and rules: https://open-figment-design-system.vercel.app/components/avatar
